### Added
- Agent tracking: a live 3D view of every agent on every connected PC, with who started which
  helper. On a desktop it is the **Agents** tab at the start of the tab strip; it is also in the
  command palette, the sidebar and More. Click an agent to open it.
  The agent with the most helpers sits in the middle and the others orbit it; a box grows with
  the helpers below it. Each box reads `agent/model: task`, with the workspace on the line below.
